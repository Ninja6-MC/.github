# Support

## Where to ask

| What you have | Where it goes |
|---|---|
| A bug, or a feature request | The issue tracker of the project it concerns |
| A question, setup help, or general discussion | [Discord](https://discord.gg/KEHaeHC8FB) |
| A security vulnerability | A private advisory, never a public issue - see [SECURITY.md](https://github.com/Ninja6-MC/.github/blob/main/SECURITY.md) |

File issues against the repository the problem is actually in. Cross-project questions
are better asked on Discord, where they can be redirected quickly.

If you are planning to send a pull request rather than report a problem, start with
[CONTRIBUTING.md](https://github.com/Ninja6-MC/.github/blob/main/CONTRIBUTING.md) - it
covers branch naming, Conventional Commits, and the `Signed-off-by` line every commit
needs.

## What to expect

Ninja6-MC is maintained by one person, in their spare time. Issues are usually read
within a few days. A reply or a fix lands when there is time for it, and an issue that
has gone quiet has not been forgotten or rejected.

Reports that include a version and the exact steps that produced the problem get
resolved considerably faster than reports that do not.
